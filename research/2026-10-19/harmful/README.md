# Preserved harmful-benchmark text

Snapshot exported on 19 October 2026 at Jonathan's explicit request for Lucas's
review on this temporary branch. These are ungraded model outputs, not an efficacy
claim or instructions endorsed by the authors. No response, NLA description or
edit was displayed to or interpreted by the exporting agent.

18 case directories; two have all four branches complete. There are 5,327 saved
NLA descriptions and 2,919 editor proposals. The stopped campaign was not
restarted to fill missing branches. Case files include exact prompts and editor
instructions for context. No activation vectors, credentials, operational logs
or full API checkpoint envelopes are included.

Each branch JSON contains its response, generated token IDs, stopping status and
all saved step texts. `nla_text` is the verbalizer output; `edited_nla_text` is the
editor proposal. Original has no NLA call; roundtrip has no edit. An absent text
means that stage was not saved, not that its text was unchanged. Some saved stages
may be ahead of the last committed response token when a run stopped.

Branches have independent prefixes: do not treat matching step indices as
identical contexts. Completion is a stopping condition, not jailbreak success.
Run-specific settings are in each case file. `index.json` includes SHA-256 hashes.
These local checkpoints can be ahead of HPC backups. Benign runs are excluded.
The exporter is `tools/export_harmful_text.py`.
