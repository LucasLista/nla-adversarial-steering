# Shared HPC access

Connect to `login1.gbar.dtu.dk` with your own DTU account, then use the shared
project directory `/work3/s216136/nla-playground`. Ask a project owner for group
access if you cannot traverse it.

See the [HPC guide](hpc.md) for commands. Read each saved configuration for
the token limit and other experiment settings.

This page grants no additional access to experiment content. Agent access is
specified in [AGENTS.md](../AGENTS.md); a human can authorize a particular review.
